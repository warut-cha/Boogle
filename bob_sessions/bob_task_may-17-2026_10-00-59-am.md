## Troubleshooting

### Error: "API key not configured"

**Solution**: Ensure `WATSONX_API_KEY` is set in `.env` and the file is in the project root.

### Error: "Project ID not found"

**Solution**: 
1. Verify your Project ID in watsonx.ai
2. Ensure `WATSONX_PROJECT_ID` is correctly set in `.env`
3. Check that you have access to the project

### Error: "Invalid credentials"

**Solution**:
1. Regenerate your API key in IBM Cloud
2. Update `.env` with the new key
3. Ensure no extra spaces in the API key

### Error: "Region mismatch"

**Solution**: Update `WATSONX_URL` to match your project's region.

### Error: "Rate limit exceeded"

**Solution**: 
1. Wait a few minutes before retrying
2. Consider upgrading your IBM Cloud plan
3. Enable `BOB_MOCK_MODE=true` for testing

### Error: "Model not available"

**Solution**:
1. Check if the model is available in your region
2. Try a different model (e.g., `ibm/granite-13b-chat-v2`)
3. Verify your watsonx.ai subscription includes the model
